## 今回行った小修正

- `scripts/analyze-project-zip.mjs` を追加し、見本ZIPの概要を機械的に確認できるようにしました。
- 同スクリプトで、シーン配列順と `timeSec` の逆転を検出できるようにしました。

3. 座標テーブル編集を追加する。
4. 名前検索・ハイライトを追加する。
