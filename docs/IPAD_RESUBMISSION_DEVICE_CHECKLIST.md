# 再審査候補の実機チェック

新しいTestFlight候補が提供された後に実施する。build17の確認結果を新buildへ自動転記しない。

## 準備

- 重要な隊列は先にZIP/.tairetsuへ書き出し、テストでは複製またはサンプルを使う。
- アプリの削除・再インストールは不要。保存データ消失の危険があるため行わない。
- メモするもの: 端末名、正確なiPadOSバージョン、アプリ版、TestFlight build番号、実施日。
- 可能ならiPad Air第5世代でも確認。手元のAir13インチ2024で確認した結果を別機種の合格としない。
- 機内モードから戻す前後でWi-Fi状態も確認する。パスワードや実メンバー名が写る画像は送らない。

## 最終提出（Codexの完了確認後）

1. App Store Connectで隊列メーカーのバージョン1.0を開く。
2. 「ビルド」で、実機確認した候補の番号を選ぶ。旧build12や未確認buildを選ばない。
3. App Review Informationに連絡先と有効な審査用ログイン情報を入力する。
4. 説明、画像、価格、カテゴリ、年齢区分、プライバシー、サポートURLを確認する。
5. 確認済み事実で確定した却下理由への返信を入力する。
6. 保存後、画面の不足項目を確認してから「審査用に追加」へ進む。最終送信はユーザー判断で行う。

この手順書の作成自体を、提出や実機確認の完了とは扱わない。
